## 🚀 Deploy to Vercel in 5 Steps

### Step 1: Open Vercel Dashboard
Go to: **https://vercel.com/dashboard**

### Step 2: Click "Add New Project"
Click: **"Add New..." → "Project"**

### Step 3: Authorize & Select Repository
1. Click **"Continue with GitHub"**
2. Authorize Vercel to access GitHub
3. Search: `mindwork`
4. Click **"Import"** on `Suhasgkashyap/mindwork`

### Step 4: Add Environment Variables
Before deploying, add:
```
DATABASE_PATH=data/mindwork.db
NODE_ENV=production
```

### Step 5: Deploy
Click the **"Deploy"** button

**That's it!** Deployment happens automatically (~2-3 minutes)
